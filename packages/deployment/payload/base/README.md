# IAF Protocol

Start with [FIRST-RUN.md](FIRST-RUN.md). This workspace uses the same task lifecycle in all three installation profiles: assignment, acceptance, execution, independent review, delivery, and closure.

The Manual profile contains files and templates. Automated adds the local runner. Unattended adds independent Windows monitoring and recovery cases. Operations Desk is an optional interface.

The installed choices and file ownership are recorded in `agentos-installation.json`. Run `IAF.ps1 Doctor` for diagnostics. Configure `TEAM.md` with your roles, then follow `PROTOCOL.md` and the hello example. Never treat execution completion, reading a report, or resolving a recovery case as delivery or task closure.
